# Clases V Tattoo

Plataforma web para una academia de Tattoo y Piercing.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- Supabase

## Qué incluye

- Portada pública del estudio
- Login y control por roles
- Cursos y clases por progreso
- Videos, PDFs y material descargable
- Panel de profesor
- Certificados
